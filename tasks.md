# Practice tasks

Use the files in `data/` as read-only inputs. Put anything you create in `practice/`.

1. Find the current directory and list the project files.
2. Enter `data/`, list its contents, and return to the project root.
3. Show the first three lines of `data/project.txt`.
4. Find every `TODO` in `data/*.txt`, including line numbers.
5. Search `data/meeting notes.txt` (note the space in its name).
6. Count matching lines. Is this counting TODO words or lines?
7. Create `practice/`, copy `starter/summary.txt` into it, search the copy, save matches as `practice/report.txt`, and verify the report.

Try each task before opening the corresponding hint in `hints/`.
